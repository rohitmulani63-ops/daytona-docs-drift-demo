# Docs Drift Checklist

Use this checklist when a README, setup guide, or release note may no longer match the code.

- Identify every command the documentation asks a user to run.
- Find the matching entry point, script, or module in the repository.
- Run or reason through the command path in a clean workspace.
- Patch the smallest amount of documentation needed to remove the mismatch.
- Ask a second reviewer to check the updated command and release note.
